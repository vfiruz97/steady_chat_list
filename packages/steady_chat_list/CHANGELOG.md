## 0.1.0-dev.9

Pre-release. The complete feature set: the simple API (`SteadyChatList.list`, `.stream`, `.source`), `MessageListHub`, `MessageListController` and `MessageListView`, paging in both directions with a bounded window, the no-jump scroll position, jumps and search navigation, optimistic sending, animated deletes, selection, visibility and read tracking, default widgets with `MessageListTheme`, saved positions (`SharedPreferencesViewportStore`), cache support, `debugOverlay` and `debugDescribe()`.

The history before the first pub.dev release is in the [repository changelog](https://github.com/vfiruz97/steady_chat_list/blob/main/CHANGELOG.md).
